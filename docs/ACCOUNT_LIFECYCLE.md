# CoCo アカウント・ライフサイクル

最終更新: 2026-09-28

## メールアドレス変更

1. ログイン中の本人が現在のパスワードと新しいメールアドレスを入力する。
2. 新しいメールアドレスへ24時間有効の確認リンクを送る。
3. リンクを開くまでは現在のメールアドレスを変更しない。
4. 確認成功時にメールアドレスを切り替え、`sessionVersion` を更新する。
5. 既存セッションはすべて無効化し、新しいメールアドレスで再ログインする。
6. 使用済み・期限切れ・競合した確認リンクでは変更しない。

## アカウント削除

CoCoでは、通報・監査ログの参照整合性を壊さないため、User行を物理削除せず匿名化する。

### 削除する本人データ

- 元のメールアドレスと公開handle
- パスワードによるログイン可能性
- 表示名、自己紹介、自動ハッシュタグ
- avatar / header
- 投稿本文、投稿画像、画像alt
- いいね、ブックマーク、リアクション
- フォロー、ブロック、ミュート
- 通知
- Y-BOCS / IES-R / ITQ / LSAS の保存結果
- password reset / email verification token
- staff recovery code
- 本人が作成した通報の自由記述
- 本人が提出した異議申立て本文

### 残すデータ

- 匿名化されたUser行
- 通報・警告・監査ログなど、運営記録の参照整合性に必要なレコード
- 運営側が作成した審査理由・管理記録

匿名化Userは永久停止状態とし、メール確認を外し、ランダム化したパスワードへ置換し、`sessionVersion` を更新するため再ログインできない。

### スタッフ

ADMIN / MODERATOR は設定画面から自己削除できない。
先に通常ユーザーへ権限変更してから削除する。

### Blob

DB上の画像参照を先に外した後、Vercel Blobの管理対象URLをbest-effortで削除する。
Blob削除が失敗してもアカウント復活は行わず、運用エラーとして記録する。
