# アカウントデータ・エクスポート仕様

最終更新: 2026-09-28

## 目的

ログイン中のユーザーが、自分の CoCo 上のデータを JSON ファイルとして取得できるようにする。

エンドポイント:

- `GET /api/account/export`

設定画面の「自分のデータをダウンロード」から実行する。

## 含むデータ

- アカウント基本情報
- 自分の投稿
- いいね / ブックマーク / リアクション
- フォロー / フォロワー / ブロック / ミュートの関係ID
- 自分宛て通知のメタデータ
- 自分が行った通報
- 自分を対象とした通報のユーザー向け情報
- 自分への運営警告と異議申立て
- Y-BOCS / IES-R / ITQ / LSAS の本人の保存結果

## 含めないデータ

- パスワードハッシュ
- スタッフ TOTP 秘密鍵
- スタッフ用リカバリーコード
- パスワード再設定トークン
- メール確認トークン
- 管理者メモ
- 内部監査ログ
- 他ユーザーのプロフィール詳細

## セキュリティ

- 認証済み userId をサーバー側で解決する。
- userId をクエリパラメータから受け取らない。
- 1ユーザーあたり1時間3回までに制限する。
- `Cache-Control: private, no-store` を付与する。
- JSON は attachment として返す。
- 心理セルフチェックは本人 userId で絞り込む。

## 将来の変更

CSV や ZIP を追加する場合でも、認証境界と除外対象は維持する。
